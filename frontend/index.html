About ResearchLens

ResearchLens is an AI-powered research paper analysis tool that helps you find, understand, and compare academic papers.

Features

  • Search papers from multiple academic databases
  • AI-generated summaries and analysis
  • Hybrid RAG retrieval for best results
  • Comparative methodology analysis
  • Interactive chat with paper context

How it works

The system uses a hybrid retrieval approach combining dense embeddings and sparse BM25 retrieval with Reciprocal Rank Fusion, followed by cross-encoder reranking for optimal results.
